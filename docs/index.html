What Orin is special for

01 / keywords
No confusing keyword names, just English words. Easy to understand while having opportunities to build a big thing.
02 / syntax
Easy to understand syntax while having simmilarities to big programming languages such as C# or Java.
03 / variables
Simple variable management, no declaring a variable type. Helps beginners learn the language fast.
